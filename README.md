# 秘境鹿屿小助手官方发布

## v8.27.3 投屏连接修复

- 修复 v8.27.1 投屏 SDK 的 JavaScript 语法错误，三个客户端在构建前完整检查脚本语法和共享协议一致性。
- 发送窗口保持可见，输入编号后点击选择屏幕并完成浏览器授权。只有接收端实际解码并确认收到画面，才报告投屏成功；失败、取消和等待状态同步回小助手。
- Windows 接收端 v1.2.0 自动接收匹配编号的投屏；自动播放受限时先显示画面，再提示开启声音。修复后的发送端兼容原 Windows v1.1.0 接收端，旧端仍需点击允许。
- Android APK 升级为 v1.2（versionCode 3），沿用原签名。没有电视实机的系统 WebView 全版本兼容性验证。
- 保留 v8.27.1 的 NAS 图标、大图视图、账号菜单、侧栏和窗口移动修改。修复目录读取指令/返回数据契约不匹配，恢复友好错误及重试卡片；缩略图在主线程创建 Tk 图片，限制后台并发为四路。
- 真实 Edge + 公共配对服务 + 合成画面测试已验证旧/新 Windows 接收端收画、确认、暂停、恢复和停止。尚未在用户电视或不同外网实机验收。


旧 Windows 1.1.0 接收端仍可使用，收到请求时点击允许。新版 Windows 1.2.0 / Android 1.2 自动接收匹配编号的投屏。已安装小助手的用户重启可在线自动升级，无需手动下载安装包。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
