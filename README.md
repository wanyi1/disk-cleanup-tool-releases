# 秘境鹿屿小助手官方发布

秘境鹿屿小助手 v8.22 封版

- 会议室投屏改用 6 位短码，自动处理编号冲突；发送端兼容旧版 12 位编号。
- 设置内新增在线自动升级：自动下载、校验发布签名和 SHA-256、退出、静默安装、重新启动，保留设置。
- Android 电视接收端 v1.1：沿用原应用签名，支持直接覆盖升级。
- Windows 接收端 v1.1.0：可拖动花朵浮窗、点击显示短码、全屏投屏。

安装文件：
- LuYuAssistant-8.22-Setup.exe：小助手 Windows 10/11 x64 安装包。
- LuYuMeetingReceiver-1.1.apk：Android 6+ 电视接收端（需支持 WebRTC 的系统 WebView）。
- LuYuMeetingReceiver-1.1.0-Setup.exe：Windows 10/11 x64 专用接收端安装包。
- LuYuMeetingReceiver-1.1.0-Portable.zip：Windows 接收端免安装版。

8.21 及更早版本需首次安装 8.22，之后可在设置里点击在线升级，无需手动下载安装包。源码保留在私有仓库。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 的用户请在「设置 → 在线升级」中一键升级。
