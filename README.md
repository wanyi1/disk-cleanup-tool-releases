# 秘境鹿屿小助手官方发布

秘境鹿屿小助手 v8.23 · NAS 文件中心

NAS 文件中心更新：

- 修复原 NAS 页嵌套滚动导致的内容截断与大片留白。
- NAS 文件夹移入左侧独立菜单，连接共享后可在小助手内浏览文件与子目录。
- 整合 SMB 登录管理：查看真实账号、清除新旧地址的登录信息、显式认证与账号核验、自动添加共享和迁移网络位置；不重启资源管理器。
- 本地只读预览图片、多页 PDF、Word 与 PowerPoint 内容、Excel 工作表、CSV 和文本等；不向外部服务上传文档，不执行宏。
- 支持文件筛选、目录分页、复制路径、放大预览和使用原应用打开。
- 独立进程处理网络读取和预览，响应超时可终止，保持主界面可用。

安装 LuYuAssistant-8.23-Setup.exe；已有 8.22 用户可直接在「设置 → 在线升级」自动升级到本版本。安装保留原设置。

投屏协议没有变化，随附 Android v1.1 APK 和 Windows v1.1.0 接收端安装包保持原版本，可继续配合 6 位短码使用。

验证：安装版实际浏览和各类本地预览通过；SMB 账号流程使用隔离测试验证；真实 NAS 密码未读取、未代替用户执行清理或切换账号。Office 预览为内容预览，复杂排版与旧版二进制文档请使用本机应用打开。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
