# 秘境鹿屿小助手官方发布

## v8.28 壁纸网络加载修复

- 必应目录、缩略图和高清原图优先使用国内入口；同一张图片的备用地址自动重试，保留收藏中的旧地址兼容。
- WinHTTP 优先直连，失败时再尝试系统代理，避免关闭代理后图片仍被旧代理设置阻塞。不修改系统代理或 VPN，也不关闭 HTTPS 证书校验。
- 分类服务不可达时优先切换可用的必应图库；旧的外部图库目录缓存不再阻挡回退。目录可用但图片全部不可达时也可恢复。
- 收藏图片加载失败时保留收藏页面和条目，提示重试，不替换为其他图片。后台结果不会覆盖已经切换的页面。
- 本版在线升级继续使用 GitHub 官方公开仓库；按用户决定撤回尚未部署的国内存储接入，不包含对象存储地址或账号信息。GitHub 本身的网络可达性仍取决于用户网络。
- 分类服务本身不可达时会明确显示「已切换必应每日」，不会将必应图库标作当前分类的搜索结果。动态壁纸、离线壁纸、收藏与原有应用方式保持。


Windows 接收端 v1.2.0 和电视 APK v1.2 沿用上一版验证文件，无协议改动。在线自动升级继续使用 GitHub。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
