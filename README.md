# 秘境鹿屿小助手官方发布

秘境鹿屿小助手 v8.24 · 体验与可靠性更新

- NAS 文件中心优化布局、素材图标、分类筛选及预览空态；修复目录切换后残留旧文件标题。
- 新增 PSD/PSB 合成画面、PDF 兼容 AI 多画板、MOGRT 内嵌图，以及 AE 同名预览图或已有系统缓存预览。
- 壁纸中心调整为推荐大图与响应式图库；修复安装环境 HTTPS 兼容问题，增加必应备用线路和内置 4K 离线壁纸，首次无网络也可使用。
- 最小化保留在任务栏；关闭时可选择退出或缩小到托盘；修复最小化触发的崩溃。
- 桌宠默认不启动，保留后续手动选择。
- 每次打开自动检查新版；确认签名有效的新版本后自动下载、校验、安装并重启。离线未确认新版时可正常使用，正在写入的任务先安全结束。

已有 8.22/8.23 用户请先在「设置 → 在线升级」中一键升级；安装 v8.24 后启用每次启动自动升级策略。安装保留原设置。

投屏协议没有变化；Android v1.1 APK 和 Windows v1.1.0 接收端安装包保持原版本，兼容现有 6 位短码。

预览说明：AI 需要保存 PDF 兼容画面；AE 工程需已有缓存缩略图或同名 PNG/JPG，无法重新渲染任意 AE 工程。Office 为只读内容预览，复杂排版请用原应用打开。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
