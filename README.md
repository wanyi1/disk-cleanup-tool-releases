# 秘境鹿屿小助手官方发布

秘境鹿屿小助手 v8.26 · 扁平工作台与体验修复

- 重做 NAS 和壁纸页面，统一浅灰背景、白色圆角卡片和蓝色主按钮，消除原生凹陷边框和粗滚动条。
- 壁纸固定三列，最小 220×145 卡片、16px 间距、310px 详情栏；保留分类、收藏、分页、离线及动态壁纸。
- NAS 固定 220/290px 两侧栏，中间文件列表拉伸；账号操作归入顶部菜单；网络中断显示友好错误和重试。原有账号、浏览与素材预览逻辑保留。
- 修复抓包报告区域裁切、清理进度反复归零和重复字节统计；增加分类本页全选。
- 新增 12 秒八路并行下载测速和停止按钮，以及先检测后修复的网络异常工具；失效本地代理可备份还原，不改静态 IP 或公司内网 DNS。
- 首页移除账号身份字样；窗口拖动交由 Windows 原生处理；优化桌宠对边缘图标的触及和走近等待，保留图标恢复与自动排列保护。
- 沿用无损素材和包体优化，全功能、全部桌宠动作和内置工具保留。本版不提供全桌面自动插帧，该需求尚待稳定开源方案验证。
- 保留启动自动检查、签名校验、自动下载安装与重启，以及原有设置。

8.24 及之后安装版重新启动可自动升级；更早支持更新的版本可从「设置 → 在线升级」进入。
Android v1.1 APK 与 Windows v1.1.0 接收端保持现有六位编号兼容，随本版提供。
预览范围：AI 需要 PDF 兼容数据；AE 使用已有缓存或同名预览图，Office 为只读内容预览。

点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
