# 秘境鹿屿小助手官方发布

秘境鹿屿小助手 v8.25 · 文件与壁纸工作台优化

- NAS 改为共享管理、文件浏览、独立预览三栏工作台，优化路径栏、文件筛选、图标、行距、空态和窄窗口布局。全部账号、共享和预览功能保留。
- 壁纸改为图片主导的图库与侧边预览；窄窗口自适应排列，缩放后缩略图重新适配，保留收藏、分页、每日壁纸、离线图库、动态壁纸及全部应用选项。
- 对运行用 PNG 进行逐像素校验的无损压缩；安装包剔除无需运行的美术原稿及字节完全相同的重复 DLL，源码保留原稿。全部桌宠、动作、内置工具与图片格式支持保留。
- 保留启动自动检查、签名校验、自动下载安装与重启；原有设置保留。

已有 v8.24/v8.24.1 安装版重新启动后可自动升级；更早版本可在「设置 → 在线升级」中一键升级。

Android v1.1 APK 和 Windows v1.1.0 接收端保持原版本与现有 6 位短码兼容，随发行包提供。

预览范围保持不变：AI 需要 PDF 兼容画面；AE 使用已有缓存缩略图或同名预览图，不渲染任意工程。Office 为只读内容预览。


点击 [下载最新版](https://github.com/wanyi1/disk-cleanup-tool-releases/releases/latest)。已安装 8.22 或更新版本的用户请在「设置 → 在线升级」中一键升级。
